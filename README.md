# Основы программирования

Лабораторные работы по дисциплине **«Основы программирования»**. Работы выполнены на C++ с использованием Qt.

## Лабораторные работы

* **Лабораторная №1** — разработка собственного валидатора строкового ввода и проверка корректности введённых данных;
* **Лабораторная №2** — разработка GUI-приложения для работы с записями о научных работах и патентах, валидация и сохранение данных;
* **Лабораторная №3** — объектно-ориентированная работа с записями: класс `PATENT`, перегрузка операторов сравнения, создание, удаление и автоматическое заполнение записей.

## Технологии

* C++
* Qt
* Qt Creator
